# -my-repository

这是一个简洁的静态前端示例仓库，包含两个独立的 HTML 页面，用于展示页面布局、样式设计和前端视觉效果。

## 项目概述

该仓库目前包含：

- `index.html`：中文介绍型页面，展示产品/技术概念相关内容，采用左右分栏布局和平台支持区设计。
- `index2.html`：简洁的样式演示页面，展示卡片/立方体风格的视觉元素。

这个仓库适合作为静态网页练习、前端课堂作业或页面原型展示使用。

## 目录结构

```text
.
├── index.html
├── index2.html
└── README.md
```

## 运行方式

### 方式 1：直接打开

直接在浏览器中打开以下任一文件：

- `index.html`
- `index2.html`

### 方式 2：本地静态服务器

在仓库根目录执行：

```bash
python3 -m http.server 8000
```

然后在浏览器中访问：

```text
http://localhost:8000/index.html
```

或者访问：

```text
http://localhost:8000/index2.html
```

## 说明

- 这是一个纯前端静态页面项目，不依赖框架或构建工具。
- 当前页面使用的是内联 CSS 样式，便于学习和展示。
- 由于仓库中未包含图片资源目录, `index.html` 中的图片插入可能需要根据实际素材进行补充。
